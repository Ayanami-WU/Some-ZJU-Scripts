## 功能

这是对原始 getSimpleAnswers 片段的整理版。脚本会扫描当前页面的 Vue 组件，寻找包含 jobList 的组件，并打开一个浮动面板，提供：

- 重新扫描页面；
- 按题目或答案筛选；
- 展示题号、题目、答案和题型；
- 在用户点击按钮后复制答案文本；
- 收起、拖动和关闭面板。

脚本优先兼容 Vue 2 的 __vue__，同时尝试读取部分 Vue 3 组件实例字段。

## 运行方法

当前目标网站的确切主机和路径尚未写入仓库，因此本版本暂时保持为控制台片段：

1. 打开本人有权访问的 ZJU E-Lang 题目页面；
2. 等题目区域加载完成；
3. 在开发者工具 Console 粘贴 zju-elang-answer-grabber.js；
4. 使用面板中的“重新读取”或“复制答案”。

确认目标 URL 后，可以再增加精确的 Userscript match 规则并提供可安装版本。

## 数据、权限与边界

- 原始代码归属于 silentle；本仓库只记录原作者授权下的再发布和面板改造。
- 该授权不等同于一个通用标准开源许可证；再次转授权或改变许可范围前，应重新取得原作者同意。
- 脚本不使用 fetch、XMLHttpRequest 或其他网络请求。
- 脚本只读取当前页面已经存在的 Vue 前端状态。
- 只在用户点击“复制答案”时使用浏览器剪贴板 API，并提供本地 fallback。
- 不自动填答、不点击提交、不修改题目数据、不处理验证码。
- optionsArray 的 title 是否代表正确答案取决于页面数据结构；面板展示的是字段推断结果，必须人工核对。
- 只应在本人有权访问的页面、测试环境或获得授权的调试场景中使用。

## 已知限制

- 依赖 Vue 组件实例仍暴露在 DOM 或可访问的组件字段中。
- jobList、optionsArray、options_answer 和 right_answer 都是页面实现细节，网站更新后可能失效。
- 原始片段中的 Markdown 标记和 __vue__ 属性写法已在本版本中整理；没有目标站点 URL 和真实页面 fixture，因此未做真实页面验证。
- 当前没有自动刷新、自动填答或提交功能。
