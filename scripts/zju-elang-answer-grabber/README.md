## 功能

这是对原始 getSimpleAnswers 片段的整理版。脚本会扫描当前页面的 Vue 组件，寻找包含 jobList 的组件，并打开一个浮动面板，提供：

- 重新扫描页面；
- 按题目或答案筛选；
- 展示题号、题目、答案和题型；
- 将题目和答案中的 HTML 转成可读文本，保留段落、换行和空位标记；
- 将已确认的题型显示为中文名称，未知编号保留数字；
- 多空答案按 (1)、(2) 等编号分行展示，便于对应原题；
- 解析 JSON 数组形式的答案，避免直接显示 JSON 代码；
- 在用户点击按钮后复制答案文本；
- 收起、拖动和关闭面板。

脚本优先兼容 Vue 2 的 __vue__，同时尝试读取部分 Vue 3 组件实例字段。

## 运行方法

当前版本为控制台片段，可在 E-Lang 的题目或答题结果页面手动运行。已核对的结果页路径为 /#/pc/listen/detail：

1. 打开本人有权访问的 ZJU E-Lang 题目页面；
2. 等题目区域加载完成；
3. 在开发者工具 Console 粘贴 zju-elang-answer-grabber.js；
4. 使用面板中的“重新读取”或“复制全部答案”。

再次粘贴新版本会替换旧面板；再次运行同一版本会展开面板并重新读取。筛选支持题目、答案和中文题型，“复制全部答案”始终复制完整列表（含多空编号）。

网站内切换页面后，面板清空旧题目并暂停复制，待题目加载后点击“重新读取”。整页刷新会卸载控制台脚本，需要重新粘贴。

## 题型映射

| type_id | 显示名称 | 依据 |
| --- | --- | --- |
| 1 | 选择题 | 真实听力和阅读页面；源码为单项选择逻辑 |
| 2 | 填空题 | 真实听力结果页；源码为文本填空逻辑 |
| 4 | 多选题 | 网站前端的多项切换和组合答案逻辑 |
| 3、6 | 文本作答 | 网站前端的 textarea 输入逻辑 |
| 5、7、8 | 选择填空 | 网站前端的逐空下拉选择逻辑 |

名称按当前交互方式归类，3、6、5、7、8 不进一步猜测具体考试子题型。文本作答缺少参考答案字段时，显示“未提供参考答案”。

## 数据、权限与边界

- 原始代码归属于 silentle；本仓库只记录原作者授权下的再发布和面板改造。
- 本目录内容按 MIT 许可证发布；再次分发时应保留本目录的 LICENSE 和归属说明。
- 脚本不使用 fetch、XMLHttpRequest 或其他网络请求。
- 脚本只读取当前页面已经存在的 Vue 前端状态。
- 只在用户点击“复制答案”时使用浏览器剪贴板 API，并提供本地 fallback。
- 不自动填答、不点击提交、不修改题目数据、不处理验证码。
- optionsArray 的 title 是否代表正确答案取决于页面数据结构；面板展示的是字段推断结果，必须人工核对。
- 只应在本人有权访问的页面、测试环境或获得授权的调试场景中使用。

## 已知限制

- 依赖 Vue 组件实例仍暴露在 DOM 或可访问的组件字段中。
- jobList、optionsArray、options_answer 和 right_answer 都是页面实现细节，网站更新后可能失效。
- 已确认的编号为 1—8，其他编号显示为“未知题型（编号）”，悬停题型可查看原始 type_id。
- HTML 只在惰性 template 中解析，最终用 textContent 展示，不继承原题的样式；图片只保留替代文字，音频、公式图等富媒体仍需查看原页面。
- 当前没有自动刷新、自动填答或提交功能。
