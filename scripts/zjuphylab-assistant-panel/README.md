## 功能

在大学物理实验周一下午选课页面提供浮动辅助面板，支持：

- 按原计划或备选方案排布 12 项实验、覆盖第 1—14 周；
- 读取教师、容量、已选状态和网页周次；
- 将方案周次预填回页面并支持撤销本地填写；
- 按顺序操作网页原有的“选课”按钮；
- 每项保留网页原生确认弹窗，等待页面显示“已选择”且周次一致后再继续；
- 在取消、满员、超时、页面变化或结果不明时暂停。

## 安装或运行

可以将 zjuphylab-assistant-panel.user.js 安装到 Tampermonkey 或 Violentmonkey，也可以在目标页面的开发者工具控制台粘贴运行。

脚本只匹配上述选课页面。当前页面地址使用校园内网 IP，离开对应网络时可能无法访问。

## 权限、网络与副作用

- Userscript 权限：none。
- 脚本自身不创建隐藏接口请求，也不轮询服务器。
- “解锁所有选项”只移除前端下拉框的 disabled，不绕过后端开放时间或容量限制。
- “填写当前方案到网页”会修改页面中的周次选择。
- “开始 / 继续逐项选课”会点击网页原有的“选课”按钮，因此可能触发真实选课业务。
- 真实选课提交属于实验性功能，必须由用户逐项确认，并在“我的课表”中最终核验。
- 不会点击“已选择”按钮，不会自动退课，不会自动处理验证码，也不会代替用户确认原生弹窗。
- 草稿和结果待核对记录保存在当前标签页 sessionStorage，不保存登录凭据。

使用前必须确认当前账号、页面和操作在授权范围内；最终以学校系统的“我的课表”为准。

## 已知限制

- 课程名称、表格结构、页面路径和 Vue 前端行为均是针对当前页面写死的。
- 需要页面只显示目标的周一下午实验列表，重复教学班或方案外已选项会导致脚本暂停。
- 前端解锁不保证后端接受，容量变化也可能使提交失败。
- 本仓库收录时未执行真实账号选课提交。
- 原始使用说明声称有离线测试，但测试代码没有随本目录收录；本次只做静态语法和仓库检查。
