## 功能

自动读取当前教学班的实验名称、教师、地点、上课时间、周次选项、容量和已选状态，不再维护固定实验名单或“周一下午”的方案。

- 自行勾选目标实验，用 ↑ / ↓ 调整排序；排序靠前的实验在自动排周时优先安排较早周次，也决定逐项选课顺序。
- 自动排周只安排勾选的实验，不会替用户增加实验、猜测必做配对或替换备选。
- 周次取自网页下拉框，支持单周、连续或非连续多周；不再限定 12 项 / 14 周。
- 已选实验自动纳入方案并固定周次；同名教学班按教师、时间和网页标识分别展示。
- 可手动修改方案周次，限定计划周次，并选择是否要求完整覆盖。
- 支持预填周次、撤销本地填写，以及逐项人工确认选课。
- 导出当前学期所有课程的已选课表为 ICS；自动读取实际日期和开始时间，多日期展开为多个事件。
- 在取消、满员、超时、信息变化或结果不明时暂停；不会自动退课或重复发送未确认的请求。

## 使用

将 `zjuphylab-assistant-panel.user.js` 安装到 Tampermonkey / Violentmonkey，或在目标页面的开发者工具控制台粘贴运行。校园内网地址可能需要对应网络。

1. 登录学校系统，打开“学生选课”，选择要安排的课程教学班。
2. 等实验列表加载完成；如脚本先于页面数据加载，点击“重新读取页面”。
3. 勾选实验，用上下箭头排序。已选实验不能取消勾选或修改周次。
4. 确认计划周次，点击“按排序自动排周”，或逐项手动选择周次。默认不要求完整覆盖；需要排满计划周次时勾选对应选项。
5. 核对名称、教师、上课时间、周次及必做要求，再预填页面或开始逐项选课。
6. 每项保留学校网页原生确认，关闭成功提示后等待页面录入；最后到“我的课表”核验。

排序用于排周优先级，不保证高优先级实验一定早于所有其他实验；已有选课、双周选项和可用周次可能限制顺序。切换账号、学期或课程后，重新读取并制定方案。

日历导出直接点击“导出已选课表 ICS”，使用当前登录账号和页面所示学期，导出已经录入学校系统的安排。草稿不会混入日历。接口只给开始时间，结束时间由“日历每次实验时长”决定，默认 145 分钟；使用前请按实际课时调整。文件按中国标准时间 UTC+8 转为 UTC，含教师、地点、学期和周次；不添加学分或虚构联系人。

## 数据来源与兼容

- 当前学校页面为 Vue2，两列表头“实验名称 / 实验详情”，详情的 `.flex` 子项依次为教师、地址、上课时间、周次、操作。
- 优先只读网页已有 `courseClassList` / `curCourse` / `currentTerm` 元数据；核对行内容后使用学期、课程、教学班 ID，避免列表重排造成误配。
- Vue 状态不可用时从当前可见表格读取，并使用名称、教师、地址、时间组成标识；无法区分的重复行会暂停。
- 星期、上午/下午来自课程元数据或当前教学班名称；具体时间取自实验行。网页未提供时明确显示缺失，不猜测。
- 实验跨度来自原始周次选项；写回时保留原始值，通过网页 `select.change` 同步。
- 学期周数、最低实验次数作为网页信息展示。必做组关系不由名称推测，需用户自行核对课程说明。

## 权限、网络与副作用

- Userscript 权限：none；没有外部依赖。
- 选课与排周不创建隐藏接口请求，不轮询服务器；等待结果仅重新读取 DOM。
- 点击日历导出后，复用网页签名 URL 和现有登录会话，仅 GET `/api/courses/uid` 与 `/api/course/lab/students/full`。固定学校服务 `http://10.203.16.55:8098/lab-course`，不跟随重定向；任一课程读取失败就停止，不下载不完整课表。
- 日历在浏览器本地生成，不引入外部依赖或导出服务器。临时读取网页已有认证头，不重新登录，不保存/打印凭据、认证头或签名 URL。课表中的学生身份、联系方式和成绩不进入日历。
- 前端解锁只移除周次下拉框的 disabled，不启用提交按钮，不改变后端开放时间或容量限制。恢复或关闭会停止保持解锁。
- 预填仅修改页面周次；撤销不取消已经提交的选课。
- “开始 / 继续逐项选课”点击学校网页原有“选课”按钮，可能触发真实业务，必须逐项人工确认。
- 不点击“已选择”按钮，不处理验证码，不代替用户确认原生弹窗。
- 草稿排序、勾选、周次、教学班上下文和待核对结果保存在本标签页 sessionStorage；账号上下文只保存指纹，不保存账号原文或登录凭据。
- 刷新恢复不会自动提交。名称、教师、地点或时间变化时要求重新制定方案；待核对记录跨教学班或账号仍会阻止继续。
- 待核对记录保存失败时不点击选课；旧版待核对记录迁移后仍要求人工核对。
